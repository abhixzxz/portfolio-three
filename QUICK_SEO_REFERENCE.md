## Quick Fixes for Common Issues

### Issue: Pages not indexed
**Fix**: Submit URL in Search Console → Request Indexing

### Issue: Structured data errors
**Fix**: Test with Rich Results Test → Fix JSON-LD syntax

### Issue: Slow page speed
**Fix**: Check image sizes → Optimize with Cloudinary → Enable compression

### Issue: Mobile issues
**Fix**: Test with Mobile-Friendly Test → Fix responsive CSS

### Issue: Crawl errors
**Fix**: Check Search Console → Fix broken links → Update sitemap
